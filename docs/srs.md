# Software Requirements Specification (SRS)

# Project Name
Pathora

## Tagline
Navigate Your Future with AI.

---

# 1. Introduction

Pathora is an AI-powered career guidance platform that helps students from Class 10 to graduation discover suitable career paths. It analyzes resumes, skills, interests, and career goals to provide personalized recommendations, skill gap analysis, and learning roadmaps.

---

# 2. Problem Statement

Many students struggle to choose the right career because they lack proper guidance. Existing platforms often provide generic advice and do not consider the student's complete profile.

---

# 3. Proposed Solution

Pathora uses Artificial Intelligence to analyze student information and generate personalized career guidance, resume feedback, and career roadmaps.

---

# 4. Objectives

- Help students identify suitable career paths.
- Analyze resumes using AI.
- Recommend skills and certifications.
- Generate personalized learning roadmaps.
- Improve career readiness.

---

# 5. Target Users

- Class 10 Students
- Class 12 Students
- Diploma Students
- Undergraduate Students
- Postgraduate Students

---

# 6. Technologies

Frontend: React

Backend: FastAPI (Python)

Database: Firebase Firestore

Authentication: Firebase Authentication

AI: Google Gemini API

Resume Parsing: PyMuPDF

Charts: Chart.js

PDF Reports: ReportLab
